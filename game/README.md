# 鎮守の里（ちんじゅのさと）

日本の神社と里の風景を配置して、そのまま歩ける Android 向けの箱庭ゲーム。

- エンジン: Godot 4.7.2（GDScript、Mobile レンダラ）
- 版: v0.1.0（applicationId `io.github.amgm087ff5.japaneselocaltown`）
- 対応: Android 7.0（API 24）以上、arm64-v8a / armeabi-v7a。権限なし（インターネット不要）
- 画面: 縦・横をセンサーで自動回転
- 設計の正本: [docs/architecture.md](docs/architecture.md)

## 遊び方

| モード | できること | 主な操作 |
|---|---|---|
| 配置 | 物を置く・動かす・回す・消す | 道具シートで物を選ぶ→地面に仮置き→ドラッグで移動→決定で確定。置いた物をタップで選択（回転・複製・削除・整地） |
| 地形 | 地面・地表・森を塗る | 道具: 上げる・下げる・平ら・なめらか・地表・森を植える・森を消す。1本指ドラッグでブラシ、2本指でカメラ |
| 歩く | 作った世界を歩く | 左下の仮想スティックで移動、画面のドラッグで見回す。一人称／三人称の切替、走る、ジャンプ、終了 |
| 撮影 | UI を隠して撮る | 画面隅の半透明の「戻る」で戻る |

カメラ（配置・地形モード共通）:
- 1本指ドラッグ: 地面をつかんで移動（配置モードで空き地を押したとき）
- ピンチ: ズーム ／ 2本指ひねり: 回転 ／ 2本指上下: 傾き
- 定位置: 真上・真横・斜め・北を上

PC での確認（マウス）: 左ドラッグ=移動、右ドラッグ=回転・傾き、ホイール=ズーム。

Android の戻るボタン: メニューや道具パネルを閉じる → 仮置き・選択を解除 → 歩行・撮影を終了 → それ以外は「もう一度押すと終了」の表示のあと、保存して終了。

## 入っている物

アセット 23 点（3Dモデルは超ローポリ。Blender スクリプトで生成）:

- 神社（13）: 拝殿、本殿、鳥居、鳥居(石)、灯籠、狛犬(阿)、狛犬(吽)、手水舎、社務所、玉垣、石段、太鼓橋、地蔵
- 自然（7）: 杉、桜、楓、松、竹（木の5種）、岩(大)、岩(小)
- 街（3）: 家(瓦)、家(茅葺)、電柱

歩行で使う人のモデル（avatar）も同梱。地表は 8 種（草・土・砂利・石畳・苔・白砂・畑・舗装）。水面（池・川）あり。

## 季節・時刻・天気

- 時刻: 0〜24時。自動で進む（既定は実時間 12 分で 1 日）。環境パネルのスライダで指定、時間の流れを止められる。
- 方角: 北が画面の上（-Z）。太陽は東から昇り南を通って西へ沈む。
- 季節: 春・夏・秋・冬。草と葉の色が変わる。桜は春に桃色、楓は秋に紅、冬は落葉樹が葉を落とす。
- 天気: 晴・曇・雨・雪。雪は冬以外でも選べ、積雪は少しずつ増える。
- 夜: 灯籠と家の窓が灯る。灯籠の光源は画質「高」のみ（最大4個）。
- 遠景: 行動範囲の外に山並みが見える。

## 保存

- 複数の世界を作れる（新規: 丘・平地・見本）。名前変更・削除もメニューから。
- 自動保存: 変更の5秒後、アプリの一時停止時、モード切替時。
- 元に戻す・やり直す: 最大30件、合計約24MBまで。
- 保存先: アプリ内の保存領域（`user://worlds/<id>.json`）。設定は `user://settings.json`。

## 画質設定

メニューの「画質」で切り替える。

| 項目 | 軽量 | 標準（既定） | 高 |
|---|---|---|---|
| 影 | なし | あり（2分割・80m） | あり（4分割・120m） |
| 描画解像度 | 0.6 | 0.8 | 1.0 |
| 光る表現（Glow） | なし | 弱 | あり |
| 森の描画距離・密度 | 70m・50% | 120m・100% | 180m・100% |
| 灯籠の光源 | 0 | 0 | 最大4 |
| 雨・雪の粒 | 300 | 800 | 1500 |

## 開発

- テスト（全件）: `game/tools/run_all_tests.sh`
- 画面のスクリーンショット: `xvfb-run -a -s "-screen 0 1600x1600x24" godot --path game --rendering-method mobile --resolution 720x1560 res://tools/shot.tscn -- out=/tmp/a.png world=sample mode=edit cam=oblique dist=60 wait=2.5`
- APK ビルド（固定鍵で署名）: `EXPECTED_CERT_SHA256=<docs/build.md の値> game/tools/build_apk.sh /tmp/chinju-no-sato.apk`

詳細: [docs/dev_env.md](docs/dev_env.md)（環境構築）、[docs/build.md](docs/build.md)（APK・署名・CI）、[tests/README.md](tests/README.md)（テスト一覧）、[docs/research_engine.md](docs/research_engine.md)（エンジン選定）、[docs/dev_notes.md](docs/dev_notes.md)（実装担当向けメモ）。

## ディレクトリ構成

```
game/
  project.godot  export_presets.cfg  main.tscn  icon.svg
  scripts/core/     Game（保存・Undo・設定）、Catalog（アセット定義）、WorldData、Geom（スナップ幾何）
  scripts/terrain/  地形・地表・水のシェーダ
  scripts/objects/  配置物・森・葉・屋根・灯り
  scripts/env/      時刻・空・遠景・天気
  scripts/modes/    カメラ・配置・地形モード・歩行
  scripts/ui/       画面UI（縦横対応）、メニュー、環境パネル
  data/catalog.json アセット定義（23点）
  assets/           models（.glb）、fonts（日本語フォント）、icons
  tests/            自動テスト（test_*.gd）
  tools/            APK ビルド、テスト、スクリーンショット、モデル生成
  docs/             設計書・ビルド・環境・調査メモ
```

## 既知の課題（v0.1）
