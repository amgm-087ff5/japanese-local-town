## 1. 屋根の種類別の約束事

### 本瓦葺
- 大棟は熨斗積(奇数段)+冠瓦、端は獅子口。降棟・隅棟あり。降棟の外端は鬼瓦、隅棟の端は二の鬼。軒先は軒丸瓦・軒平瓦。根拠: 出典 [JAANUS 降棟](https://aisf.or.jp/~jaanus/deta/k/kudarimune.htm) / [JAANUS 隅降棟](https://aisf.or.jp/~jaanus/deta/s/sumikudarimune.htm)、research.md §5
- 熨斗段数の通例(奇数段)、獅子口の意匠: 要確認

### 銅板葺・檜皮葺
- 銅板一文字葺は屋根面を水平に一直線に葺く。根拠: 出典 [杉並区 資料](https://www.city.suginami.tokyo.jp/documents/7598/04-the-tekigaiso-revival-2-4.pdf)
- 降棟・隅棟は出典では瓦の部材として定義される。入母屋の銅板平葺に降棟・隅棟が無いという仮説は未検証。根拠: 要確認(仮説。ユーザー指摘 2026-10-25 17:41 が発端)
- 箱棟・鬼板の銅板屋根での構成: 要確認
- 箕甲は、破風を持つ妻側で屋根面が垂れて破風へ回り込む部分。根拠: 出典 [JAANUS 箕甲](https://aisf.or.jp/~jaanus/deta/m/minokou.htm)
- 箕甲の「むくり」(曲面の形): 要確認(ユーザー指摘 2026-10-25 17:41 は「けらば=箕甲のむくり」)
- 「箕甲」を隅の檜皮の総称とする資料もあり、JAANUS と食い違う。根拠: 出典 [堺市 資料](https://www.city.sakai.lg.jp/kanko/rekishi/bunkazai/bunkazai/bunko.files/tajihayakoukai.pdf) / 要確認
- 銅板を檜皮・柿の下に葺き込み防腐に使う例がある。根拠: 出典 [文化財研究所 報告](https://www.tobunken.go.jp/ccr/pdf/51/5126.pdf)
- 檜皮葺の軒付は軒先を厚く積む(厚さ40cm の事例)。根拠: 出典 [本願寺 唐門 資料](https://www.hongwanji.kyoto/see/pdf/karamon_08.pdf)
- 柿葺の軒付は軒付板で厚みを作り、その上を平葺きする。根拠: 出典 [weblio 杮葺](https://www.weblio.jp/content/%E6%9D%AE%E8%91%BA)

## 2. 軒先とけらばの造りの違い
- 軒先 = エッジの効いた反り、けらば = 箕甲のむくり。根拠: ユーザー指摘(2026-10-25 17:41)。むくりの出典は要確認
- 銅板の軒先・けらば水切り: 銅板 t0.5、曲げ 50×50(糸巾100)。根拠: 出典 [新宿御苑 工事図面](https://www.env.go.jp/garden/content/000328089.pdf)

## 3. 比率の目安
- 破風板 厚: ヒノキ t30mm。根拠: 出典 [新宿御苑 工事図面](https://www.env.go.jp/garden/content/000328089.pdf)。research.md 6.2 の 0.065(垂木成の0.7〜1倍)は要確認値で、t30 と乖離。ユーザー指摘(2026-10-25 17:41「破風板が厚すぎ」)と同じ方向。再検討が必要。
- 破風板 成(見付け)・屋根全体に対する比率: 要確認
- 軒付 厚: 檜皮の例で 40cm。銅板葺の軒付の厚み・段数: 要確認
- 銅板 厚: 一文字葺 t0.35mm。根拠: 出典 [新宿御苑 工事図面](https://www.env.go.jp/garden/content/000328089.pdf)
- 瓦 厚: 15〜20mm。根拠: 出典 [GSJ 地質ニュース](https://www.gsj.jp/data/chishitsunews/99_04_06.pdf)、research.md §5
- 垂木・木割・柱間・軒の出・勾配: research.md §2〜§3 を参照(一般知識による目安、要確認)

## 4. 破風板の構成
根拠: 出典 research.md §6 (JAANUS 破風・拝み・眉・登り裏甲・破風尻・破風金具 の各項)
- 垂直に立てた厚板。見付は垂直面。
- 妻の頂部は拝み(2枚の継手)。拝みに懸魚を付ける。
- 下縁に眉欠き(帯と彫り溝)。破風尻で繰形に沿って消える。
- 上端に登り裏甲・登り茅負の段が2〜3本の水平線として出る(段の寸法は research.md §6.2 を参照、要確認)。
- 拝み・破風尻・中間に金具(唐草打ち出し・猪目・鋲・六葉)。文様の詳細は要確認。
- 唐破風は中央が起り両端が反る。頂部中央の懸魚は兎毛通(根拠: 出典 [JAANUS 唐破風](https://aisf.or.jp/~jaanus/deta/k/karahafu.htm))。

## 5. 技術面の学び
- GLB 出力では Blender の手続き型テクスチャが消える。焼き込み(ベイク)が必要。根拠: ユーザー提供の作業上の学び
- 木目は部材の長手方向に UV を取る。根拠: ユーザー提供の作業上の学び
- 仕上げ違い(丹塗・白木・古色など)は KHR_materials_variants で切り替える。根拠: ユーザー提供の作業上の学び
- 浮き・めり込みはヘッドレス MCP で検査する(research.md §4 の手順)。根拠: research.md §4 の検証結果
- 凍結版はフラグ方式で新機能を ON にし、旧版と頂点・面の差分 0 を確認する。根拠: ユーザー提供の作業上の学び
- 屋根の曲面は十分に分割する。根拠: ユーザー提供の作業上の学び
- ブラウザキャッシュ対策にビルド ID を付ける。根拠: ユーザー提供の作業上の学び
