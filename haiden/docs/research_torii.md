# 明神鳥居 調査メモ（3Dモデリング用）

調査日: 2026-11-01
目的: 一般的な明神鳥居の部材構成・木割・比率を集め、丹塗明神鳥居（柱径0.30m・高さ約4.5m）のモデリング寸法を決める。特定の鳥居の丸写しはしない。
表記: 「要確認」は出典なし、または出典間で食い違うもの。「計算値」は出典の比率から導いた値。

---

## 0. 要点

- 明神の判別点は「笠木の両端が反り上がる」「島木がある」「貫が柱の外へ出る」「柱が内転びする」。神明はこれらがない。
- 木割の比率は複数の出典で整合した。柱間S（柱心間）を基準にすると、高さ≒1.25S、柱径≒S/10、笠木全長≒貫全長≒5S/3、貫の出（柱心から）≒S/3。
- 指定の柱径0.30m（高さ4.5m）は、サンプル中で最も細い（d/H=0.067）。木割（S/10）に従うと柱径は0.36m。どちらを採るかは要判断。
- 台輪は明神の王道形式には出てこない。台輪は台輪鳥居の部材。
- 笠木・島木・額束・貫の断面寸法、反りの量、根巻・金具の仕様は、調べた範囲では数値の出典が見つからなかった。要確認。

| 楔（くさび） | 貫が柱を抜けた側に両側から打ち込む。 | 鹿島鳥居の記述では楔、明神は貫が柱から出る方式。 | [aisf 明神](https://aisf.or.jp/~jaanus/deta/m/myoujintorii.htm)、[kotobank](https://kotobank.jp/word/%E9%B3%A5%E5%B1%85) |

| 扁額 | 額束に掛ける。明神の標準部材とまでは言えない。 | 亀岡八幡宮の石鳥居に青銅の鳥居額あり（[県指定](https://www.pref.miyagi.jp/soshiki/bunkazai/15kameoka.html)）。 | 同左（要確認） |
| 台輪（だいわ） | 明神の王道形式には出てこない。台輪は台輪鳥居の部材。長崎の例は「明神系台輪鳥居」で台輪あり。 | 柱頂に載る円形の蓋状材。 | [kotobank](https://kotobank.jp/word/%E9%B3%A5%E5%B1%85)、[長崎市 PDF](https://www.city.nagasaki.lg.jp/uploaded/attachment/3606.pdf)、[aisf 明神](https://aisf.or.jp/~jaanus/deta/m/myoujintorii.htm) |
| 柱の転び（うちころび） | 明神は柱が内側へ傾く。角度の数値は出典になし。 | 「内転」とも。 | [aisf 明神](https://aisf.or.jp/~jaanus/deta/m/myoujintorii.htm)、[aisf 転び](https://aisf.or.jp/~jaanus/deta/k/korobi.htm) |

## 2. 比率（木割）

柱心間を S、柱径を d、地上高を H とする。

| 項目 | 比率（推定） | 根拠・整合性 | 出典 |
|---|---|---|---|
| 地上高 H と柱心間 S | H ≒ 1.25 S | 八坂神社（北九州）4.51/3.61=1.25。標準鳥居（bananas）3.4/2.7=1.26。 | [北九州市](https://www.city.kitakyushu.lg.jp/contents/02100290.html)、[bananas](https://sean-reid.github.io/bananas-for-scale/thing/standard-torii-gate/)（bananas は要確認度が低い） |
| 柱径 d | d ≒ S/10 | 16世紀末以降の規定として記載。八坂は 0.47/3.61=0.13（石は太め）。標準 0.30/2.7=0.11。 | [aisf 鳥居](https://aisf.or.jp/~jaanus/deta/t/torii.htm) |
| 笠木の全長 | L_kasagi ≒ 5S/3 | 比率 3:5（柱間:笠木全長）の記述。八坂 5.87/3.61=1.63（5/3≒1.67）。 | [carpentryway](https://thecarpentryway.blogspot.com/2013/03/japanese-gate-typology-31.html?m=1)、[北九州市](https://www.city.kitakyushu.lg.jp/contents/02100290.html) |
| 貫の全長 | 5S/3（計算値含む） | 「貫が重なる部分の柱の心々距離の5/3が貫の総長」（江戸中期の木割と一致とする）。 | [代田八幡 論文](https://www.cst.nihon-u.ac.jp/research/gakujutu/55/pdf/I-14.pdf) |
| 貫の出（柱心から） | S/3（全長の1/5） | 貫の両端を柱心間の1/3ずつ突出させる記述と、「全長の約1/5が出る」の記述が一致（計算: (5S/3−S)/2=S/3）。 | [aisf 鳥居](https://aisf.or.jp/~jaanus/deta/t/torii.htm)、[aisf 明神](https://aisf.or.jp/~jaanus/deta/m/myoujintorii.htm) |
| 貫の下端 地上高 | ≒ S（内法 S−d も候補） | 匠明（1608）の「柱の縁から作る正方形に内接する円の最上部に貫下端を合わせる」を正方形の辺=S とみなすと上端=S。明神記述は「柱の下端の内側の間隔と等しい」。 | [aisf 鳥居](https://aisf.or.jp/~jaanus/deta/t/torii.htm)、[aisf 明神](https://aisf.or.jp/~jaanus/deta/m/myoujintorii.htm)（要確認） |
| 笠木・島木の下端と貫の間隔 | ≒ d | 「貫は島木・笠木の下に柱径とほぼ等しい距離を空けて配置」。17世紀以前は大きくばらついた。 | [aisf 鳥居](https://aisf.or.jp/~jaanus/deta/t/torii.htm)（要確認: どの面からの間隔か不明） |
| 柱の転び | 片側へ内傾（角度は未確定） | 転びの一般指標: 「半転」（底径の半分）、「八つ中の転」（底径の1/8）。これは鳥居専用ではない。 | [aisf 転び](https://aisf.or.jp/~jaanus/deta/k/korobi.htm) |

### 大型・石の柱間変化（参考）

亀岡八幡宮（6m）は柱心間が下部5.53m、上部4.9m。つまり柱が内側へ傾く。片側の内傾量は約0.3m（高さ方向の対応位置は未記載）。比率 S/H は 0.92 で、他例（1.25）より小さい。鳥居の高さ・形式で比率はばらつく（要確認）。

## 4. 仕上げ・金具・石鳥居の違い

### 木造（丹塗）
- 色: 朱（丹塗）と黒を併用とする記述（明神: [aisf](https://aisf.or.jp/~jaanus/deta/m/myoujintorii.htm)）。奴禰鳥居は笠木・台輪・切妻部材・柱基部が黒、他は赤橙（[aisf 奴禰](https://aisf.or.jp/~jaanus/deta/n/nunetorii.htm)）。
- 明神の笠木・島木を黒、柱・貫を朱とする配色は一般的な組み合わせとされるが、出典は未確認（要確認）。
- 朱は水銀朱の時代があり、防腐・防虫の意味があったとする（[san-tatsu](https://san-tatsu.jp/articles/382952/)）。
- 金具（笠木端の飾り金具）: 出典で見つからず。要確認。

### 石鳥居（花崗岩・稲井石など）
- 柱は継ぎ足しの例あり（八坂神社の石鳥居は高さ約8mで、約3m高さに継ぎ目。[keihan](https://www.keihan.co.jp/navi/kyoto_tsu/tsu202001.html)）。
- 神明系の石鳥居の貫は角柱状で、笠木の端は円柱状（大岩稲荷田宮神社。[中央区](https://www.city.chuo.lg.jp/a0052/bunkakankou/rekishi/bunkazai/kuminbunkazai/oiwainaritamiyajinjyanotorii.html)）。
- 石は柱間・柱径が大きく太め（d/H 0.10前後）。
- 基部は台石・藁座が中心。

## 6. モデリング用の推奨寸法（丹塗明神鳥居・柱径0.30m・高さ約4.5mを基準）

すべてm。「計算値」は本ファイル第2節の比率から算出。

| 部位 | 寸法 (m) | 根拠 |
|---|---|---|
| 地上高（笠木上端） H | 4.50 | 指定値 |
| 柱心間 S | 3.60 | 計算値（H/1.25） |
| 柱径 d | 0.30（推奨は 0.36） | 指定値。木割 S/10 だと 0.36。サンプル中の d/H は 0.08〜0.11 で、0.30 は 0.067 と薄い。 |
| 柱の内法 | 3.30 | 計算値（S−d、d=0.30） |
| 笠木 全長 | 6.00 | 計算値（5S/3） |
| 笠木の柱心からの出 | 1.20 | 計算値（S/3） |
| 笠木の柱外面からの出 | 約1.05 | 計算値（1.20−0.15） |
| 島木 全長 | 要確認（笠木と同等か短め） | 出典は「島木は笠木より小さい」の記述なし。要確認 |
| 貫 全長 | 6.00 | 計算値（5S/3） |
| 貫の柱心からの出 | 1.20 | 計算値（S/3 = 全長の1/5） |
| 貫の下端 地上高 | 3.60（内法 3.30 も候補） | 計算値（S）。要確認 |
| 笠木・島木の下端〜貫の間隔 | 0.30 | 木割「柱径とほぼ等しい」。要確認 |
| 笠木 断面（成×幅） | 要確認（推定 0.20×0.30） | 出典は標準鳥居の笠木厚0.2（bananas）のみ。要確認 |
| 島木 断面（成×幅） | 要確認（推定 0.15×0.30） | 出典なし |
| 貫 断面（幅×成） | 要確認（推定 0.20×0.30） | 出典なし |
| 額束 | 要確認 | 出典に寸法なし |
| 台輪 | なし | 明神王道は台輪なし（台輪鳥居の部材） |
| 柱の内転び | 片側 上端で 0.08〜0.16 程度（推定 1〜2°） | 亀岡八幡の柱心間変化からの推定。要確認 |
| 笠木の反り量 | 要確認（数値の出典なし） | 両端が上がる記述のみ |
| 笠木の端切り | 内側への斜め切り（角度は要確認） | 明神の記述 |
| 色 | 柱・貫: 朱。笠木・島木: 黒（要確認） | 配色の記述あり |

柱径を 0.36 にする場合の変更点: 柱の内法 3.24、貫・笠木の出は変わらない（S 基準のため）。

## 7. 要確認点（優先順）

1. 柱径: 指定 0.30 は木割（S/10=0.36）より細い。0.30 で行くか 0.36 にするか判断。
2. 笠木・島木・貫の断面寸法（成・幅）: 数値の出典が見つからず。
3. 笠木の反りの量、両端の切り角度: 数値なし。
4. 島木の有無: 神明の島木の有無で出典が食い違う（[san-tatsu](https://san-tatsu.jp/articles/382952/) と他出典）。明神は島木ありで統一して問題ない見込み。
5. 貫下端の地上高: S（3.60）か内法（3.30）か。
6. 笠木・島木と貫の間隔（柱径とほぼ等しい）: どの面の間隔か不明。
7. 額束の寸法: 出典なし。
8. 金具・根巻（黒の銅板）・亀腹の形状: 木造の仕様は出典が見つからず。
9. 地中根入れの深さ: 英語の出典に「約7フィート」の記述あり（[carpentryway](https://thecarpentryway.blogspot.com/2013/03/japanese-gate-typology-31.html?m=1)）。木造の一般寸法としては大きすぎる可能性があり、要確認。
10. 柱の内転びの角度: 出典に数値なし。
