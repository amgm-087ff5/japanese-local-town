# 拝殿モデル仕様

- 形式: 入母屋造・平入・桁行3間×梁間2間・正面1間向拝(軒唐破風)・銅板葺(段葺)・丹塗り
- 座標: X=桁行、Y=梁間(正面 -Y)、Z=上。単位 m。パラメータは `haiden/blender/params.json`

# 拝殿A-2(本瓦葺 + 千鳥破風)

- 生成: `python3 haiden/blender/build_haiden.py --variant A-2 --out haiden/out/A-2`(A-1 は `--variant A-1 --out haiden/out/A-1`)
- 定義: `haiden/blender/variants/A-2.json`(params.json への差分上書き)。屋根組立は `haiden/blender/roof_hongawara.py`、瓦テンプレート・棟・鬼は `haiden/blender/hlib/kawara.py`
- 軸部・組物・軒(垂木)・妻・向拝・縁などは A-1 と共通コード。屋根仕上げだけを差し替え、正面に千鳥破風を追加
- A-1 との差: `roof.type=hongawara`、軒付(瓦座下の野地)厚 0.27→0.12、銅板の段(step_lip)なし → 屋根面高さは A-1 より約0.15m低い基準面に瓦(約0.12m)が載る

## 千鳥破風(A-2 のみ)
- 配置: 大屋根正面の中央、向拝(軒唐破風)の真上背後。妻面 y=-2.57(大屋根軒先から流れ方向 d=1.25)、破風板は妻面から 0.38 前へ。
  向拝屋根が大屋根に取り付く線(d=1.15)のすぐ上に妻を立て、唐破風の背後に三角の破風が重なる(参考画像1・3と同じ構成)
- 大きさ: 破風の半幅 1.80(全幅3.6 ≒ 向拝の幅4.2の0.86倍、唐破風の起り幅3.1より少し広い)、軒→棟の高さ約1.3(照り屋根 勾配0.6→0.9)、
  棟頂は大棟の頂より約0.4低い。破風板 高0.30(拝み)→0.17(破風尻)に細る
- 小屋根: 本瓦葺(大屋根と同寸)。千鳥破風の棟は前から大屋根の流れに突き当たる(熨斗5段+冠、前端に鬼瓦+鳥衾)。破風沿いに降棟(熨斗3段)と小鬼
- 谷: 千鳥破風の流れと大屋根の流れの交線(谷)を数値的に求め、両側の瓦を谷線に沿って斜めカット(谷あき0.10、谷板は野地面に沈めた溝)、谷底に **谷板(銅板・緑青)**
- 妻の足元: 大屋根の瓦は妻壁の手前で止め、**雨押え熨斗**1段+冠
- 妻飾り: 妻壁(黒漆)+ 木連格子(丹)+ 猪目懸魚(白木 0.5×0.5)+ 六葉
- パラメータ: `variants/A-2.json` の `chidori`(halfw, d_front, overhang, raise, 勾配, 破風高, 懸魚寸法)

## ポリゴン・GLB
- 瓦はテンプレート(平瓦52 tris・丸瓦140・軒平約770・軒丸約1000・掛瓦144)を numpy でスタンプして種類ごとに1オブジェクト(配列化)
- GLB 書き出しは実体化メッシュ。Draco(edgebreaker、位置14bit・法線10bit・UV12bit 量子化)で ~4MB。
  EXT_mesh_gpu_instancing は、隅・谷で瓦を個別に斜めカットしているため同一メッシュの再利用率が低く、Draco後のサイズも十分小さいので不採用
